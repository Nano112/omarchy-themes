# Apoapsis

A deep-space dark theme. Backgrounds are NASA imagery (public domain, per NASA
media usage guidelines) pulled from images.nasa.gov and cropped to 2880×1800.

| File | Image | Credit |
|---|---|---|
| 1-orbital-night | Milky Way over the Earth limb, ISS Exp. 44 (iss044e045215) | NASA |
| 2-cosmic-cliffs | "Cosmic Cliffs", Carina Nebula, JWST NIRCam | NASA / ESA / CSA / STScI |
| 3-saturn-eclipse | "A Splendor Seldom Seen", Saturn backlit, Cassini (PIA14934) | NASA / JPL-Caltech / SSI |
| 4-earth-limb | Earth limb at night, ISS Exp. 62 (iss062e081621) | NASA |
| 5-earthrise | Earthrise over the Moon, Apollo 17 (as17-152-23272) | NASA |

`unlock.png` is an original orbital-ellipse glyph drawn in the theme accent.

Source and build instructions: `~/code/omarchy-themes`.
